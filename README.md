# Axiel PDF

**AI-powered PDF automation for high-volume document workflows.**

Axiel PDF is an open source Python project designed to process, organize, analyze and merge large volumes of PDF files with intelligent automation.

It combines bulk PDF processing, OCR, AI-assisted renaming, duplicate detection, spelling validation and text extraction to help users manage document workflows faster, safer and more reliably.

---

## Current Status

Axiel PDF is currently in early development.

The first public release is being prepared. This repository is open to document the project vision, roadmap and development progress.

---

## Key Features

- Bulk PDF merging
- High-volume PDF processing
- OCR text extraction
- AI-assisted file renaming
- Duplicate PDF detection
- Spelling and text validation
- PDF organization workflows
- Local-first document processing

---

## Use Cases

Axiel PDF is designed for workflows such as:

- Organizing large batches of scanned documents
- Merging multiple PDF files into structured outputs
- Extracting text from scanned PDFs using OCR
- Detecting duplicated documents in large folders
- Renaming files intelligently based on extracted content
- Checking document text for spelling issues
- Preparing document batches for storage, review or automation

---

## Why Axiel PDF?

Many document workflows involve hundreds or thousands of PDF files that need to be reviewed, renamed, merged, checked or organized.

Axiel PDF aims to reduce manual work by combining PDF automation, OCR and AI-assisted document intelligence in one open source tool.

## Privacy First

Axiel PDF is designed with a local-first mindset.

The goal is to process documents locally whenever possible, reducing dependency on external services and helping users keep sensitive documents under their control.
